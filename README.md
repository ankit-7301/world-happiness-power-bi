# World Happiness Report — Power BI
World Happiness Report analysis and interactive dashboard built using Power BI.

An interactive Power BI dashboard analyzing happiness scores and related indicators across countries.

## Dashboard Visuals

* Country with highest GDP per capita
* Highest and lowest happiness scores
* Country-wise happiness score table
* GDP per capita vs. happiness score
* Global country map
* GDP per capita by country
* Social support by country
* Corruption indicator comparison

## Tools Used

* Microsoft Power BI
* CSV Dataset

## Files

* `Happiness Score Data.csv` — Cleaned dataset
* `Happiness Score Project.pdf` — Dashboard preview
* `World Happiness Report.pbix` — Power BI report

## Key Insight

Finland has the highest happiness score, while South Sudan has the lowest in this dataset.
